# Fintiex SEO: first technical pass, September 11, 2026

## Baseline and implemented changes

The production build contains 454 public indexable HTML pages (excluding the two framework error documents). All already had canonical URLs, descriptions, and one H1. This pass repairs specific crawl and discovery defects rather than rewriting all metadata.

- robots.txt blocked /_next/, which contains scripts and styles used to render the site. Removed that rule; admin and API paths remain excluded.
- Sitemap contained 414 URLs and omitted 40 published pages: 15 calculators, 9 card categories/tools, 7 mortgage pages, and 9 savings account pages. It now covers all 454 public canonical pages.
- Removed build-time lastModified from the sitemap. A deployment is not proof that every page's content changed.
- Removed Article schema's invented default publication date and build-day modification date. Explicit dates supplied by content are retained.
- Fixed 15 broken URL targets in guides, glossary articles, investing pages, and savings review links. Added permanent redirects for old links/bookmarks, and updated internal links directly where authored.
- Differentiated private student-loan and refinancing review titles, resolving the Earnest duplicate title.

## Validation

Run `ANALYTICS_ENABLED=true pnpm --filter @fintiex/web build`, then `python3 scripts/audit-seo.py` from the repository root. The audit checks rendered canonical/title/description/H1 coverage, unique titles, exact sitemap coverage, duplicate sitemap entries, internal destination resolution against built routes/redirects, and rendering asset access. It does not assert rankings, Google indexing, Core Web Vitals, or financial accuracy.

## Search opportunities and next work

The manually captured Search Console snapshot covers June 9–September 8, 2026 and only the first 100 visible query rows, not all queries or property totals. Examples: liberty mutual auto insurance (2,032 impressions, average position 22.8); marcus hysa (529 impressions, position 17.1); cd ladder calculator (157 impressions, position 40.8); best business credit cards (1,380 impressions, position 64.3). These are prioritization inputs, not evidence that title changes alone will raise rankings. Confirm query-to-page mapping in Search Console before making landing-page decisions.

1. **Savings rate accuracy and consistency.** The savings hub has conflicting APYs between editorial cards and the separate account-data list. Verify every offer against the provider, consolidate data sources, show actual checked dates, and qualify conditional offers. Review the site's claims of live/daily updates against the implemented data workflow.
2. **Search Console indexing diagnostics.** Inspect excluded pages, Google-selected canonicals, sitemap processing, and query-to-page matches. Automatic account access remains unconnected; do not treat the snapshot as a live feed.
3. **High-impression landing pages.** Review Liberty Mutual auto insurance and Marcus HYSA against the queries above, with verified terms, clear comparisons, and useful internal links. Review calculator intent and output explanations next.
4. **Editorial trust.** Confirm real authors/reviewers, methodology, evidence supporting scores, source links, and update responsibilities. Do not invent credentials or customer review counts.
5. **Performance and regional-page quality.** Measure field/lab performance and assess whether each state page offers meaningful local value before expanding content.
