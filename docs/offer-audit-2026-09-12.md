## Partner reporting
Admin applications/revenue CSV import is implemented. Network + opaque conversion ID is an idempotency key. Records can move from submitted to approved to paid, or rejected. Approved-but-unpaid commission and paid commission are separate, and currencies are grouped separately. No person-level attribution or completed application is inferred from an outbound click. No partner API has been configured: network account details and its attribution parameter are still needed.
